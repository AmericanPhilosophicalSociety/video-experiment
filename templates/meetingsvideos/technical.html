Technical

Meetings Video is implemented as a custom Python/Django application developed by the Center for Digital Scholarship at the American Philosophical Society. The project code is open source and available on Github.

Custom Software

The CDS actively develops open source software to advance its projects. The following packages were developed or enhanced for this project:

  • video-experiment
  • loc-authorities
  • asr-tools

Technologies used:

This project relies upon an ecosystem of existing open source software. The project team thanks the maintainers of these software packages for their work which made this project possible.

  • Python
  • Django
  • PostgreSQL
  • htmx
  • Video.js
  • Universal Viewer
  • Webpack
  • Islandora
  • NVIDIA NeMo
  • vLLM

AI Use Disclosure

Transcripts for videos were generated using NVIDIA Parakeet (nvidia/parakeet-tdt-0.6b-v2), an automatic speech recognition model. Transcripts were proofread by human reviewers and corrected mostly for incorrectly identified proper names. Initial summaries for talks were generated using a locally run version of Gemma (google/gemma-4-26B-A4B-it). All machine generated summaries were reviewed by a human reviewer for stylistic consistency and factual accuracy.
